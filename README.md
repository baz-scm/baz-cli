# Baz CLI — Vendor Integration Testing

This repository allows external vendors to test their integration with [Baz](https://baz.co).

## Documentation

- [Google Docs Integration](https://docs.baz.co/basics/integrations/google-docs)
- [Monday.com Integration](https://docs.baz.co/basics/integrations/monday)

## How to Test Your Integration

1. **Create a ticket/item** in your vendor system (Monday.com or Google Docs).
2. **Integrate the vendor** with Baz by following the relevant documentation linked above.
3. **Open a pull request** with the ticket info in the PR title.
4. **See it in action** — Baz will enrich the review context using the linked ticket, so you can verify the integration is working correctly.
